# Hiệp's Room Portfolio

A bilingual personal story portfolio built around an interactive 3D room. Visitors can explore meaningful objects to learn about my journey, values, life beyond coding, and what I am still discovering.

## Local development

```bash
npm install
npm run dev
```

Run `npm run build` to create a production build.
